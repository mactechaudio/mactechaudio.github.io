Questions

Which Macs does it run on?

Any Mac running — Apple Silicon or Intel. It runs natively on both, so it doesn't need Rosetta.

How does uninstalling work?

When a .pkg installs, macOS keeps a receipt listing every file it wrote. Batch Pkg Manager reads that receipt, shows you what it found, then removes those files — plug-in and app bundles completely, shared folders only if they end up empty — and forgets the receipt. For installer apps that don't leave a receipt, it can trace what they install first.

Is uninstalling safe?

You always see what will be removed before anything happens, and you confirm it. It only removes what a package's own receipt (or trace) lists, and it skips anything another installed package also owns. As with any uninstaller, removal can't be undone — keep a backup (e.g. Time Machine) of anything important.

Why does it ask for my admin password?

Installing and removing system-wide software (in /Applications or /Library) requires administrator rights on macOS. You enter it once per batch, in Apple's standard dialog. Batch Pkg Manager never sees or stores it.

How many Macs can I use my license on?

Two at a time. Moving to a new Mac? Choose “Deactivate License on This Mac…” from the app menu first, then activate on the new one.

Does it work offline?

Yes. The license is checked with the license server when you're online; a validated license keeps working offline for 30 days.
